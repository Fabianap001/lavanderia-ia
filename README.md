# 👕 Analizador de Marquillas

Proyecto universitario que identifica símbolos de lavado en marquillas de ropa usando IA.

## 🛠️ Tecnologías
- Node.js + Express (backend)
- Python + FastAPI (servicio IA)
- OpenAI GPT-4o mini (modelo de visión)
- HTML/CSS/JS (frontend)

## ⚙️ Instalación

### 1. Clonar el repositorio
```bash
git clone https://github.com/Fabianap001/lavanderia-ia.git
cd lavanderia-ia
```

### 2. Configurar la API key
Dentro de la carpeta `python-service`, crea un archivo `.env`:
### 3. Instalar dependencias Python
```bash
cd python-service
pip install fastapi uvicorn openai python-multipart python-dotenv
```

### 4. Instalar dependencias Node.js
```bash
cd backend
npm install
```

## 🚀 Ejecutar
Doble clic en `arrancar.bat`

¡Listo! La aplicación abre automáticamente en el navegador.
